# Public-content privacy blacklist

The following material must not be added to this public portfolio or its audit reports:

- Personal compensation, salary, income or contract/payment details. Compensation sections were removed from `docs/old/dao_van_hung_work_timeline.md`; no values are repeated here.
- FPT/client names, internal source, schemas, endpoints, tickets, screenshots, datasets or business process detail.
- Student, teacher, parent or center-member names, contact details, attendance, grades, schedules, account data or operational records.
- Private health profiles, food/medical records, model prompts, user conversations, or other personal health data from NanoBio.
- Our Story personal photos, generated memory content, letters, personal messages or relationship details. Technical source paths may be cited only where the cited path contains no personal content; do not link to the live experience or republish media.
- Credentials, API keys, tokens, passwords, connection strings, service-role keys, private CI values or any secret from any repository.
- Private PDFs, chat history, local notes or source documents that are not mounted and approved for publication.

Public repository source is not permission to copy private datasets, media or personal content into the portfolio. Reports keep descriptions high-level and link only to public, safe source paths and SHAs.
