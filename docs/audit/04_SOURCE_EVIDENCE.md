## Audit boundary

The commit window is 2026-08-24 00:00 through 2026-10-24 23:59 +07. Full branch/tag refs and window commits were fetched for all non-empty repositories. The NanoBioAI full-history clone stalled while Git was indexing a large pack, so that repository was fetched with all branch/tag refs and a shallow boundary at the requested window. Its earlier history is not represented in the local audit clone. The current package files used below were read by pinned SHA/path. No app in the 16-project source set was built, tested, deployed, or connected to a production service as part of this portfolio audit.

The “window commit” counts are unique Git commit objects reachable from fetched refs. They may contain shared team and upstream commits. They do not establish individual authorship or contribution size. File/path changes were reviewed at each commit. For the personal story project, individual ref names, subjects, and filenames are withheld; only aggregate coverage and technical path groups remain.
