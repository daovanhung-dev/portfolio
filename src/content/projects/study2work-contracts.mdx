## Bài toán

Monorepo EdTech/HRTech có nhiều ứng dụng, tài liệu contract và module backend. Reviewer cần thấy rõ đâu là API/event contract, đâu là phần tích hợp service đã có trong source.

## Phần việc

- Đối chiếu tài liệu API contracts với module tương ứng trong repository.
- Map event contracts với ứng dụng và service liên quan.
- Phân biệt thiết kế contract với service composition.
- Xác định Work API trong nhánh được rà soát sử dụng Express 4.

## Kết quả thể hiện trong mã nguồn

Source mapping làm rõ các contract, module và ranh giới tích hợp trong phạm vi đã kiểm tra.
