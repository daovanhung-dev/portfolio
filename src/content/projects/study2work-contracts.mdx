## Tổng quan

Study2Work là monorepo EdTech/HRTech với nhiều ứng dụng, tài liệu API contracts và module backend.

## Điểm kỹ thuật

- Đối chiếu contract với module trong từng ứng dụng.
- Theo dõi riêng API, event contracts và các điểm tích hợp.
- Work API trong nhánh được tham chiếu dùng Express 4.

Cách trình bày theo từng module giúp làm rõ ranh giới giữa thiết kế API, source và tích hợp dịch vụ.
