Ba repository liên quan một domain nhưng có phạm vi và thời điểm triển khai khác nhau.

## Cách tiếp cận được ghi nhận

- Đọc riêng README và đường dẫn source của từng repository
- Đặt FastAPI/PostgreSQL là implementation lịch sử
- Giữ Angular/Supabase ở scope hẹp hơn
- Gắn các flow finance/payroll vào source Vue mới hơn
