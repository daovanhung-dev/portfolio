## Bối cảnh

Khi yêu cầu, phản hồi API và kết quả trên giao diện khác nhau, cần tái hiện vấn đề và lần theo luồng xử lý từ UI đến dữ liệu.

## Cách tiếp cận

- Đối chiếu yêu cầu, thiết kế chi tiết và test case.
- Tái hiện với input và dữ liệu kiểm soát.
- Truy vết UI → API → service → SQL.
- Sửa trong phạm vi được giao và chạy regression.

## Kết quả

Quy trình theo từng tầng hỗ trợ khoanh vùng nguyên nhân và kiểm tra thay đổi một cách có hệ thống. Nội dung công khai giữ kín hệ thống, mã nguồn và dữ liệu khách hàng.
