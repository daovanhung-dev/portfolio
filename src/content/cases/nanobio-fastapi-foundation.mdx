## Bối cảnh

Sản phẩm Flutter có các thành phần Supabase hiện hữu và một foundation backend Python được tổ chức riêng.

## Cách tiếp cận

- Xác định package root và phụ thuộc.
- Tổ chức API bằng FastAPI theo module.
- Thiết lập nền tảng SQLAlchemy, PostgreSQL và Alembic trong source.
- Phân định package/setup với tích hợp runtime theo môi trường.

## Kết quả

Foundation tạo cấu trúc backend FastAPI và persistence để tiếp tục tích hợp theo nhu cầu triển khai.
