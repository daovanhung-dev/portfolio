## Bối cảnh

Monorepo EdTech/HRTech có nhiều ứng dụng, tài liệu contracts và module backend cần được kết nối theo từng dịch vụ.

## Cách tiếp cận

- Đối chiếu branch và SHA liên quan.
- Map tài liệu contracts với module source.
- Phân tách API/event contracts khỏi service composition.
- Theo dõi Work API dùng Express 4 và các điểm tích hợp theo từng ứng dụng.

## Kết quả

Tài liệu API và module source được đặt trong cùng bối cảnh, giúp làm rõ contracts, công nghệ và ranh giới giữa các dịch vụ.
